## Where the project stands (2026-10-17)

Working on the real board: protocol, board access, simulator, command-line tool (CSV, JSON, `--serve`), MCP server, graphical application with four screen styles, three themes, English and Portuguese, dBm display from 35 to 60 MHz (approximate elsewhere), a generator screen and a license check of every dependency. All hardware tests pass (S1 must be on for them).

Known limits, on purpose:

- The dBm calibration was measured with a function generator at 35 to 60 MHz and is applied everywhere with an `approximate dBm` badge outside that range. The generator amplitude was not checked with an oscilloscope, so absolute values are approximate. Above 60 MHz the shape of the response is not calibrated. An optional way to measure it with SMA attenuators is in `calibration.md`.
- The state of the S1 button cannot be read from the board (`serial-protocol.md`); the application can only infer it from a sweep with the output cabled to the input.

## Behaving like a real spectrum analyzer

Goal: the application works like a real bench spectrum analyzer. Gaps found so far, in the suggested order:

1. ~~Immediate reaction to changes.~~ Done. The board ignores commands while it sends a sweep, so a sweep cannot be aborted; the application sweeps in segments of 100 points (about 0.13 s) and looks at the new settings between segments.
2. **Several markers.** A real analyzer has several markers, delta mode (difference between two points) and a peak table. Here there is one marker (M1) with peak search, next peak and marker to center.
3. **Trace modes.** Clear and write, average with a counter (`Avg 4/10`), max hold, min hold, view (freeze) and blank. Here: average of 1, 4 or 16, max hold, min hold and clear hold.
4. **Save and export.** Screenshot and CSV of the trace. Not implemented.
5. ~~Level in dBm.~~ Done for 35 to 60 MHz (approximate elsewhere).
6. **Knob and step behavior.** Real analyzers step the span in a 1-2-5 sequence and let the user set the center step. Here the knob steps are proportional to the span.
7. **Single sweep.** One sweep on demand, besides continuous sweeping.
8. **Span and center interplay.** Setting the center keeps the center exactly and shrinks the span if it does not fit inside the board's limits (35 MHz to 4.4 GHz); setting the span keeps the center when possible but shifts the range at the limits. Decide whether the span should also keep the center and shrink.

Not possible on this board, so no keys for them: RBW and VBW control, input attenuator, preamplifier, detector choice.

## Hardware reminders

- Never send unknown commands to the board: it goes silent until the USB cable is replugged.
- The function generator used for calibration (FeelElec FY6900) may power up with its outputs on and a high amplitude: read the output state and amplitude, switch the outputs off and set a low amplitude before connecting anything to the board.
- The board input takes at most +5 dBm.
